# API Reference

HTTP API is contract-first.

## Source of truth

`packages/contracts/openapi.yaml` owns endpoint shapes, schemas, and operation IDs.

Generated outputs:

- Go OpenAPI types: `server/internal/api/gen`
- TypeScript OpenAPI schema: `packages/api-client/src/generated/schema.ts`
- Public TypeScript domain types: aliases exported from `packages/api-client/src/index.ts`

## Runtime

- Swagger UI: `/api/docs`
- Raw OpenAPI YAML: `/api/openapi.yaml`

Use Swagger for endpoint details. Keep MDX docs focused on product concepts, workflows, and architecture.

When adding API fields, edit the OpenAPI spec first, run `pnpm generate`, then update handlers and UI callers.
