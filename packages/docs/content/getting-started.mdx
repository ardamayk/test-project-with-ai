# Getting Started

## Prerequisites

- Go 1.23+
- Node 22+ and pnpm
- [mise](https://mise.jdx.dev/) (recommended)

## Development

```bash
pnpm install
mise run dev
```

- API: http://localhost:8090
- Web dev server: http://localhost:3000 (proxies `/api` to Go)

### Music library

Point the server at one or more local folders (comma-separated):

```bash
export MUSIC_PATHS=/path/to/music,./music
```

Then open **Library** in the web UI and click **Scan library** to index audio files (mp3, flac, ogg, m4a, opus, wav).

## Production build

```bash
mise run build
./bin/server
```

Single binary serves the SPA, MDX docs, and API.
