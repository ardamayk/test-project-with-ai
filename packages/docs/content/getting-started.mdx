# Getting Started

## Prerequisites

- Go 1.23+
- Node 22+ and pnpm
- [mise](https://mise.jdx.dev/)

## Development

```bash
pnpm install
mise run dev
```

- API: http://localhost:8090
- Web dev server: http://localhost:3000 (proxies `/api` to Go)

### Music library

Add music through **Managed Import**: open **Tracks** in the web UI, click **Import Music**, and select audio files or a local folder (mp3, flac, ogg, m4a, opus, wav). Every file is validated strictly, shown in an Import Preview, and stored in Managed Storage only after you confirm.

The server never scans a server-side folder; Managed Import is the only way music enters the library.

### Managed Storage

Managed imports use one server-owned storage root. The server keeps a 2 GiB safety reserve by default and enforces configurable per-file and per-batch streaming limits:

```bash
export MANAGED_STORAGE_PATH=./data/managed
export MANAGED_STORAGE_RESERVE_BYTES=2147483648
export MANAGED_IMPORT_FILE_LIMIT_BYTES=2147483648
export MANAGED_IMPORT_BATCH_LIMIT_BYTES=2147483648
```

All byte-count settings use base-10 integer strings. Set `MANAGED_STORAGE_RESERVE_BYTES=0` only when intentionally disabling the safety reserve.

## Production build

```bash
mise run build
./bin/server
```

Mise is the canonical interface for development and CI tasks. Run `mise run ci:fast` for static checks and unit tests, `mise run ci:integration` for integration tests, or `mise run ci:full` for the full local policy. Target one artifact or domain with commands such as `mise run web:build`, `mise run server:test`, and `mise run desktop:check`; root pnpm commands are compatibility proxies.

### Git hooks

`pnpm install` enables local Husky hooks. Pre-commit formats and checks staged JavaScript, TypeScript, JSON, Go, and Rust source while preserving partial staging. OpenAPI drift verification runs only when generation inputs are staged. Pre-push runs the complete `mise run ci:fast` policy.

These hooks provide bypassable local feedback; CI is authoritative. Pass `--no-verify` to `git commit` or `git push` when needed. Hook installation is disabled in CI and production dependency installs. When `graphify-out/` exists, Graphify post-commit and branch-switch updates run if `graphify` is available on `PATH`; otherwise they intentionally do nothing.

Single binary serves:

- React SPA at `/`
- MDX product docs at `/docs/`
- Swagger UI at `/api/docs`
- OpenAPI YAML at `/api/openapi.yaml`
