# Layout Customization

The web UI uses a modular **widget shell** from `@repo/ui`.

## Layout model

Preferences are stored on the server and synced across devices:

```json
{
  "sidebarPosition": "left",
  "panels": {
    "left": ["now-playing"],
    "right": ["discover"]
  },
  "collapsed": { "left": false, "right": false },
  "sizes": [22, 50, 28]
}
```

Update via `PATCH /api/v1/preferences`.

## Adding widgets

Register widget IDs in `packages/ui/src/widgets/registry.tsx`.

Domain widgets should stay near their owning feature. Shared shell primitives stay in `packages/ui/src/layout/`.
